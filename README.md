# 현대차 수행/업무기사 성과급 계산기

2026년 현대차 수행/업무기사를 대상으로 한 성과급을 계산하는 단일 HTML 정적 페이지입니다. 입사일, 근속 기간 등의 조건을 입력하면 차수별 성과급과 예상 실수령액을 자동으로 계산해 보여줍니다.

## 배포 URL

https://<GITHUB_USERNAME>.github.io/<REPO_NAME>/

(푸시 후 실제 주소로 교체)

## 성과급 구성

| 차수 | 지급 기준일 | 지급 내역 |
| --- | --- | --- |
| 1차 | 노사서약일 (9월 2일 예상) | 기본급 300% + 870만원 |
| 2차 | 11월 30일 | 400만원 |
| 3차 | 12월 31일 | 기본급 100% |

## 입사일팩터 정의

```
입사일팩터 = (지급기준일 − 입사일) ÷ (지급기준일 − 1월 1일)
```

- 2025년 이전 입사자는 1.000으로 고정
- 지급기준일 기준 근무 2개월 미만인 경우 0.000
- 지급기준일이 입사일로부터 2년을 넘는 차수는 퇴사 처리로 간주해 지급 대상에서 제외

## 소득세 계산 방식

소득세는 2025년 실제 급여명세서 4건에서 역산한 상여 원천징수 방식을 적용합니다. 별도의 세율표나 국세청 공식 대신, 실제 명세서에 반영된 원천징수 결과를 기준으로 근사한 값입니다.

## 로컬 실행

빌드 과정이나 별도 서버 없이, `index.html` 파일을 웹 브라우저로 바로 열면 동일하게 동작합니다.
